### Аудит правил: найдено и исправлено

1. Storage принимал любой `video/*`, функция тоже. Теперь только `video/mp4`: приложение всегда загружает MP4, другие контейнеры проходили мимо сжатия.
2. Не было жалоб и блокировок, которых требуют сторы. Добавлены `reports` и `users/{uid}/blocks`. Блокировка проверяется в правилах профиля, истории рекордов, приглашения и принятия связи.
3. Согласие на обработку данных нигде не фиксировалось. Профиль без `consentAt == request.time` не создаётся, поле не меняется.

Проверено без изменений: чужие тренировки, планы и рекорды недоступны без активной связи; `approved` и любые записи в `records` и `leaderboard` с клиента запрещены; роль тренера и модератора клиент не выставит и не снимет; ник уникален; неподтверждённый email не пишет ничего.

### Остаточные риски

- Создание залов не ограничено по частоте. Автоматизацию сдерживает App Check, мусорные залы удаляются в консоли.
- `coachStudents/{coachId}` читает любой вошедший: нужно для проверки лимита. Видно только число учеников.
- Содержимое подходов в тренировках правила не проверяют: правила не умеют обходить списки. Проверяет приложение, документ видят только владелец и его тренер.
- Enforce App Check для Firestore и Storage включается в консоли после проверки метрик (`docs/firebase-setup.md`). До этого правила работают и без токена.

### Замеры

На машине этапа нет Android SDK и устройства, поэтому цифры не сняты.

| Показатель | Цель | Значение |
|---|---|---|
| Холодный старт | до 2 с на среднем устройстве | не измерено |
| Кадры в списках | 60 FPS, без janky-кадров | не измерено |
| Размер AAB / APK arm64 | минимальный | не измерено |

Как снять на устройстве среднего класса:

1. Холодный старт: `flutter run --profile --trace-startup`, затем значение `timeToFirstFrameMicros` из `build/start_up_info.json`. Пять запусков после остановки приложения, взять медиану.
2. Кадры: `flutter run --profile`, DevTools → Performance. Прокрутить таблицу рейтинга, историю тренировок и список учеников, записать долю кадров дольше 16 мс.
3. Размер: `flutter build apk --release --target-platform android-arm64 --analyze-size` и `flutter build appbundle --release --obfuscate --split-debug-info=build/symbols`.

## Допущения ⚑

- Токены сессии хранит Firebase Auth SDK, отдельного хранилища токенов нет, поэтому `flutter_secure_storage` не нужен.
- Принятие связи тренер-ученик остаётся в правилах: они атомарно проверяют сторону, свободного ученика и лимит тренера. Перенос в функцию не меняет `CoachLinkRepository`.
- Жалобы разбираются в Firebase Console, модераторского экрана жалоб нет.
- Блокировка не скрывает пользователя из рейтинга.
- Профили, созданные до этапа 6, не имеют `consentAt`. Пользователей в продакшене ещё нет.
