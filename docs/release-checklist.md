# Чек-лист публикации

Отмечать по порядку перед каждой отправкой в стор. Настройка Firebase: `docs/firebase-setup.md`.

## Открытые вопросы перед первой публикацией

- [ ] Почта поддержки. Сейчас в политике и условиях контакт — Issues репозитория: публичный канал не подходит для запросов на удаление данных. Завести почту и вписать её в `docs/legal/*.md`.
- [ ] Ссылка на удаление аккаунта без приложения (обязательна в Google Play → Data safety). Нужна веб-страница или почта из пункта выше.
- [ ] Юридическое лицо или ФИО разработчика для аккаунтов стора и раздела «Кто обрабатывает данные».
- [ ] Замеры из `docs/security-performance-report.md`: холодный старт, кадры в списках, размер AAB. Без них этап 6 закрыт без цифр.
- [ ] Регион Firestore и Storage в консоли Firebase — ЕС (политика обещает обработку в Google Ireland). Функции уже в `europe-west1`.

## Версия

- [ ] `version` в `pubspec.yaml`: `X.Y.Z+N`, `N` растёт с каждой загрузкой в стор.
- [ ] `dart format .`, `flutter analyze`, `flutter test` чистые.
- [ ] Тесты правил и функций на эмуляторе зелёные (команды в отчёте этапа 6).
- [ ] `firebase deploy --only firestore:rules,firestore:indexes,storage,functions` на боевой проект.

## Иконка и сплэш

Исходники: `assets/branding/*.svg` и PNG 1024×1024 из них. После замены:

```
dart run flutter_launcher_icons
dart run flutter_native_splash:create
```

- [ ] Иконка на домашнем экране Android (круглая и квадратная маска), тематическая иконка Android 13+.
- [ ] Сплэш на Android 11, Android 12+, iOS в светлой и тёмной теме системы.

## Android

1. Ключ загрузки, один раз, хранить вне репозитория и в резервной копии:
   ```
   keytool -genkey -v -keystore <путь>/upload-keystore.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
   ```
2. Скопировать `android/key.properties.example` в `android/key.properties` и заполнить. Файл в `.gitignore`. Без него релиз подписывается отладочным ключом и Google Play его не примет; Gradle пишет предупреждение.
3. Сборка:
   ```
   flutter build appbundle --release --obfuscate --split-debug-info=build/symbols
   ```
4. Сохранить `build/symbols` и `build/app/outputs/mapping/release/mapping.txt` вне репозитория под номером версии, загрузить символы в Play Console.

- [ ] Play App Signing включён. SHA-256 ключа загрузки и ключа подписи Google добавлены в Firebase (Android-приложение) — без них не работают Google Sign-In и Play Integrity.
- [ ] App Check: в консоли Firebase подключён Play Integrity.
- [ ] Разрешение `SCHEDULE_EXACT_ALARM`: в Play Console объяснить — таймер отдыха; на Android 14 пользователь выдаёт его сам.
- [ ] Data safety: email, ник, данные о здоровье и фитнесе (тренировки, вес и рост), видео, идентификатор устройства для App Check. Шифрование при передаче — да. Удаление по запросу — да. Передача третьим лицам — нет.
- [ ] Целевая аудитория 16+, приложение не для детей. Возрастной рейтинг по анкете IARC.
- [ ] Ссылка на политику конфиденциальности: `https://github.com/meloton01/Good-GYM/blob/main/docs/legal/privacy-policy.en.md` (или свой домен через `--dart-define=LEGAL_BASE_URL`).
- [ ] Закрытое тестирование: Google требует для новых личных аккаунтов 12 тестировщиков в течение 14 дней до открытого релиза.

## iOS (на macOS)

1. Xcode → Runner → Signing & Capabilities: команда разработчика, Bundle ID `com.goodgym.goodGym`, автоматическая подпись.
2. Capabilities: Sign in with Apple, App Attest.
3. Сборка:
   ```
   flutter build ipa --release --obfuscate --split-debug-info=build/symbols
   ```
4. Загрузить через Transporter или Xcode Organizer, символы сохранить вне репозитория.

- [ ] App Check: в консоли Firebase подключён App Attest.
- [ ] App Privacy в App Store Connect: те же данные, что в Data safety, привязаны к пользователю, для трекинга не используются.
- [ ] Описания разрешений камеры, микрофона и галереи в `Info.plist` совпадают с реальным использованием.
- [ ] Удаление аккаунта из приложения работает (требование Apple 5.1.1(v)).
- [ ] Вход через Apple доступен рядом с Google (требование 4.8).

## Страница в сторе

- [ ] Название «Good GYM», краткое и полное описание на английском, русском и украинском.
- [ ] Скриншоты 360×640 и крупнее: рейтинг, подача рекорда, тренировка, история с графиком, профиль. Без выдуманных данных: снимать на тестовом проекте с настоящими тренировками.
- [ ] Ссылки на политику и условия в карточке стора совпадают со ссылками в приложении.

## Финальная проверка на устройстве

- [ ] Регистрация, подтверждение email, вход через Google и Apple, сброс пароля.
- [ ] Полный цикл тренировки без сети и синхронизация после включения.
- [ ] Подача рекорда с видео, одобрение модератором, появление в рейтинге.
- [ ] Связь тренер-ученик: приглашение, принятие, разрыв.
- [ ] Экспорт данных и удаление аккаунта.
- [ ] Крупный шрифт системы, узкий экран, системная настройка «уменьшить анимацию».
